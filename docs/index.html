01 / Read what runs

Nothing left
to guess.

Not an opaque intermediate representation. Not shorthand that hides a second language. A compiled Lisp with explicit types, named call arguments, and visible control flow.

Builtins wear #. Generators wear @. Even arithmetic states its type and overflow behavior.

02 / Built for generation. Designed for inspection.

The machine writes it.
You can understand it.

A

Explicit by construction

Strong static types, no type inference. Free-standing functions, no methods, function pointers, or closures. No recursion. Named call arguments show what each value means; explicit operations show what each function does.

B

Concrete all the way down

Full monomorphization through code generation, rather than user-facing generic types. Pure generators produce concrete Lim definitions. Their output is source you can read, search, and review.

(@#optional (: type #u64 : name MaybeU64))
C

Less indirection. More evidence.

Generated source lives in .lim, with call-site provenance. Hash-based caches reuse unchanged generator inputs and dependencies. Inspect the actual implementation, not just a macro invocation.

03 / Explicit does not mean unchecked

Small surface.
Serious checks.

The compiler follows ownership and borrowing across the program—not just the function in front of you. Explicit source and static checks work together: auditability is not a substitute for safety.

Global borrow checking
Interprocedural analysis tracks returned references and retained borrows without user-written lifetime annotations. Borrowed storage must remain valid, and exclusive access must stay exclusive.
Linear ownership
Values are linear by default. Moving transfers ownership; copying requires explicit support. Linear locals must be consumed before return. Destruction is explicit, not silently inserted.
A visible unsafe boundary
Safe code is checked for memory safety. Raw pointers and unsafe operations have an explicit boundary; unsafe code still needs an audit. Safety checks are not a claim of formal verification.

04 / Time is part of the design

Fast to build.
Native to run.

A dependency-free Rust compiler with its own native instruction encoding and ELF linking. No external assembler or linker in the normal executable build path.

Cached generation avoids repeating unchanged work. Reachability-based emission keeps unused functions out of executable builds. Concrete implementations keep runtime dispatch visible.

Speed is an engineering target, not a universal timing guarantee. Measure your workload with the compiler benchmark harness.

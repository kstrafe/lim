What runs here
Scalar #u64, #i64, #usize, #isize, #bool and (); safe functions and named calls; wrapping arithmetic, comparisons and bit operations; local mutation; branches, blocks and loops; predicate contracts. The normal checker runs before code generation.
Each example prints through the explicitly declared browser-print-u64 binding, which writes unsigned decimal lines through lim.print_u64; unsafe-call rules still apply. Check only can validate arrays, references, structs and other features that lack runnable WebAssembly support. Running currently excludes memory access, globals, aggregates, matching, saturating arithmetic, floats, narrow integers, labeled/value loops and general host I/O. The index-evidence example checks and passes a bounded scalar index; it does not read array memory. File imports are unavailable. #usize values retain Lim’s 64-bit scalar semantics here.
This is an experimental teaching backend. The full language reference also describes the broader native compiler.

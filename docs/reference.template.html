A language for people & machines · experimental

Explicit code.
One place to look.

Lim is a human-readable intermediate representation for code you can inspect, test, and ship. A strongly typed Lisp, it combines Rust-inspired whole-program borrow checking with proof-oriented ideas from Lean 4: validated branches carry facts that later calls must satisfy. Concrete generated implementations keep behavior visible, with fast compilation and efficient native code as core goals.
